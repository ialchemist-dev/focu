# 研究记录：Olivier & Muir《World Models for Active Measurement》数字核查（FOCU #46）

## 总览

- **问题：** #46 中引用的数字，哪些由论文支持，哪些只出现在作者帖子或公司博客，哪些还不知道？
- **结论（一句话）：** “89% 低于地质统计”和“约 40% 低于 Claude”的出处已经找到，是 Fleet 2026-11-13 的博文 [S4]，LinkedIn 帖复述了这两个数字 [S5]。它们针对**两个真实斑岩铜矿床**上的留出钻孔，和论文摘要里的合成世界结果是两回事。NeurIPS 公开摘要 [S1] 没有这两个数字，而且明确说向野外迁移是“下一步”。论文全文 [S3] 被 OpenReview 浏览器验证拦住，**无法确认全文或附录里有没有这些数字**，所以只能标为“目前只见于博文和帖子；论文是否包含仍未知”，不能说它们是假的。
- **已核实（S1 摘要层面，合成数据）：** 400 个诊断世界，Cu-mass IoU 从 0.071（不钻）升到 0.308（20 孔）；打乱钻孔测值后降到 0.028。1,536 个留出世界上，学习到的排序策略在公共区域的增益为 0.0564，预测铜靶向为 0.0464，随机为 0.0276。由此算出 21.6% 的相对优势（D1）。
- **未核实：** issue 中“96 个世界、比普通克里金低约 75%”[S7] 不在 S1 版本的摘要里，OpenReview 版本读不到。

## Q4 对地下 ML / 地热的意义（推断）

- 框架层面（推断）：把“隐藏状态基本静止、行动只揭示证据”的主动测量问题，换成“下一口井打在哪里信息量最大”，在形式上可以迁移到地热勘探中的温度、渗透率建模。但论文的目标函数是铜质量，摘要说效益在该目标上最强 [S1]，**没有证据表明地热目标上同样有效**。
- 合成世界生成器需要特定矿床类型的过程规则（博文中是斑岩铜钼系统 [S4]）。换成地热需要新的生成器和新的验证，这一点是推断。
