4. 对地下 ML / 地热的意义（推断）

叙事综合 以下是推断，不是来源中的事实。论文把问题写成“隐藏状态基本静止、行动只揭示证据”，再用模拟测量结果来训练“下一孔打在哪里”S1。这种表述在形式上也适用于地热勘探里的温度场和渗透率重建。不过有三点限制：（1）摘要说效益在训练用的铜质量目标上最强 S1；（2）合成世界生成器针对斑岩铜钼系统 S4；（3）野外表现目前只有公司声称 S4 S6。所以这项工作没有证明可以迁移到地热。若要借鉴，可以先学它的评估设计：打乱测值做对照，以及在钻探邻域之外的公共区域上比较增益。
