# v0.2 implementation milestones

The first delivery is M0/M1, not a claim that all v0.2 capabilities are complete.
Keep user-defined sources, source-grounded standalone reporting, single-host
scripts, audio plus script, and independently recoverable stages.

| Milestone | Delivery | Acceptance |
|---|---|---|
| M0/M1 (this change) | Config/cursor fixes, versioned URL IDs, transactional SQLite, backlog, frozen selection, coverage, lock/resume, CLI, legacy import | Repeated/reordered RSS and cross-transport items dedup; quotas leave backlog; failed writes/TTS do not advance cursors/coverage; retry/concurrency do not overwrite finalized episodes |
| M2 | HTTP retries/conditional requests, one official HTML adapter, enrichment, source diagnostics | Timeout/429/markup changes are classified; pagination completeness is explicit; one failed source does not stop healthy ones |
| M3 | Provider/prompt loading, summaries/translation, actual coverage output, versioned feedback/profile updates and undo | Feedback updates the intended setting only; script constraints hold; rule/prompt provenance is inspectable and reversible |
| M4 | Reproducible installer/locks, doctor/capabilities, validated Muse/OpenClaw setup | A clean machine can install and verify an artifact; repeated setup preserves config; one scheduler owns the job |
| M5 | Versioned lists, catalog, validate/import/export/update, PR/CI registry | Another agent can reuse a list; repeated import dedupes sources; updates preserve overrides; export excludes private history/credentials |

## M1 decisions

One data directory is one profile. Source and content identities are separate.
Query parameters that identify content are retained. Unbroadcast items persist
and age out by configured retention, with identity tombstones retained. Source
quotas limit selection, not acquisition. Coverage means finalized generation,
never inferred listening. Failed episodes reserve their frozen inputs until the
original date is resumed. v0.1 imports are explicit and preserve backups.

## Next smallest changes after M1

1. Add bounded HTTP retries, Retry-After, ETag/Last-Modified and structured source
   diagnostics. Validate one official HTML collector with stored markup fixtures.
2. Add long-body enrichment/summarization, replacing the explicit skeleton with
   a versioned provider protocol and actual per-item coverage.
3. Persist feedback_events and profile_versions when the processing contract is
   ready; use bounded structured patches and undo, not automatic code edits.
4. Make installation reproducible and validate real Muse/OpenClaw versions rather
   than inventing their discovery paths/commands.
5. Promote examples/groups to data-only versioned list packages (author namespace,
   description/license, sources, compatibility and defaults). Start with a GitHub
   catalog and PR submissions; no accounts, payment, comments, scoring or personal
   recommendations. Pin versions/checksums and show update diffs before adopting
   new sources. Local overrides win; secrets/history never travel with a list.

Defer semantic event clustering, model fine-tuning, full-platform browser
collection, multi-user hosting and an MCP server until the local contract works.
